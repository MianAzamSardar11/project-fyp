# Final-Year-Project-
 Sociavo is a digital marketing agency website developed in PHP and MySQL.

It includes a fully functional frontend and admin dashboard.

The site is responsive, dynamic, and designed for real-world usage.

Built and tested using XAMPP on a local server.

Technologies Used

Frontend: HTML5, CSS3, JavaScript

Backend: PHP 7+

Database: MySQL (phpMyAdmin)

Server: Apache via XAMPP
